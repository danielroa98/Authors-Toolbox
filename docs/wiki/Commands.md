# Commands

Every command is in the command palette (Ctrl/Cmd + P) under **Authors Toolbox**. You can assign hotkeys to any of them in **Settings → Hotkeys**, and on iPhone and iPad add them to the mobile toolbar in **Settings → Mobile**.

|---|---|---|

| Check spelling & grammar: selection | right-click menu (with a selection) | See [Spelling and grammar](Spelling-and-grammar). |
| Check spelling & grammar: current section | | The chapter or scene around the cursor. |
| Check spelling & grammar: whole note | | |
| Clear spelling & grammar underlines | | |
| Set note language: Español / English / auto-detect | panel's language menu | Saves or removes the `lang` property. |
